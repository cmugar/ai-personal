What changes

Less glare at the top, same floor at the bottom. Primary text drops from 17.1:1 to 10.9:1 and secondary from 11.0:1 to 6.8:1, while muted text barely moves (5.5 to 5.3). Like the light half, the text levels sit closer together.

The page is warm, not black. The default's near-black page against near-white text is the main source of glare at night. Darkroom lifts the page to charcoal and pulls the text down to bone.

One blue in both modes. Buttons use the same slate blue fill as light mode, with white text. Links lighten to #75A8DF so they read on charcoal. The button sits at about 3:1 against the panels, so it stands out by colour more than by brightness.

The diff is the brightest thing on screen. Git green and red stay the app's saturated defaults, which glare more on charcoal than on paper.

Code colours are approximate. The default panel colours its code with its own role colours so the two compare like for like; the app's real default code highlighting may differ.
