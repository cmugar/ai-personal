What changes

The top of the text range comes down, the bottom comes up. Primary text drops from 18.7:1 to 10.1:1, but muted text rises from 3.4:1 to 4.6:1. The text levels are closer together, so the page reads as one even gray instead of black headlines over faint captions.

Colour collapses to one hue. The default spends colour on blue, green, red, amber and violet. Darkroom keeps a single slate blue in both modes and drains the rest toward gray, so the cursor, send button and toggle are the only things that pull the eye.

The diff is the exception. Git colours stay the app's saturated green and red, the brightest marks on the page. Setting them is the obvious next change.

Code colours are approximate. The default panel colours its code with its own role colours so the two compare like for like; the app's real default code highlighting may differ.
