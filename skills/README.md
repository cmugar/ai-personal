# Skills

Each skill is a folder holding a `SKILL.md`, in the open Agent Skills format
(agentskills.io). Keep to the core frontmatter (`name`, `description`) and plain
instructions so a skill stays portable across tools; a skill that runs scripts only
works where the tool can execute code.

Each tool reads skills from its own folder, so installing means copying or linking
a skill folder into that tool's skills directory. Check the tool's docs for the path.

Empty for now. Add a skill when you notice yourself repeating the same instructions.
